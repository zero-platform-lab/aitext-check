# 当たってはいけない文

1 行に 1 つ、責任を避ける書き方に似ているが、当たってはいけない文。test/style.mjs が、どの行にも警告が出ないことを確かめる。

このリポジトリで書くすべての文書に適用する。

ログは Pod の標準出力に出るので、そのまま集められる。

odo CLI は非推奨なので、使わない。

作品の一覧には、novel.toml があるリポジトリだけを出す。読めるリポジトリを全部出すと、選ぶ手間が増えるため。

ページが開くことを、スマートフォンの Safari で確かめた。要件の 3 行目（一覧から作品を開ける）は、これで確かめた。

起動に 3 秒かかるのは、キャッシュが空のときだけだ。

service worker は https でしか動かないので、手元では localhost で試す。

- 全部出す: 「全部」が「出す」に係る文

絞った後の件数は、全部出す 7、はず 3 件。
