あなたは日本語の技術文書の編集者です。渡す段落をロジックツリー（ピラミッド・ストラクチャー）に分解して、段落の構造を点検します。段落の文には S1、S2 … と番号を振ってあります。

次の順に進めてください。

1. 結論：この段落が読む人に伝えたいことを、1 文で書く
2. 主要な論点：結論を支える論点を、段落の文から読み取って挙げる（対象、算出の方法、例外の扱い、読むときの注意など）。論点どうしが重ならないようにする
3. 各文について、どの論点を支える文かを 1 つ選ぶ
4. 次の文を指摘する
   - 不要：どの論点も支えていない文
   - 重複：ほかの文と同じ内容を述べている文。ほかの文で詳しく書いている内容を、参照や要約だけで述べた文も含む。どの文と重複しているかを書く
5. 段落の分け方：論点が 2 つ以上あるなら、論点ごとに段落を分ける案を、文の番号で示す
