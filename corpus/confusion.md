# 取り違えやすい動詞の組

英語の意味の広い動詞を、日本語の意味の広い動詞に直訳した形と、技術文書で定着した動詞の組。
bin/find-confusion.mjs は、書いた「名詞＋助詞＋口語の動詞」の頻度を、同じ名詞と助詞の定着した動詞の頻度とコーパスで比べる。

| 英語 | 口語の動詞 | 定着した動詞 |
|---|---|---|
| get, acquire | 取る | 取得する、獲得する |
| output, compute, show | 出す | 出力する、表示する、算出する |
| make, create, generate | 作る | 作成する、生成する |
| guard, protect | 守る | 保護する |
| add | 足す | 追加する |
| delete, remove | 消す | 削除する |
| send | 送る | 送信する |
| call, invoke | 呼ぶ | 呼び出す |
| run, execute | 走る、回す | 実行する |
| change | 変える | 変更する |
